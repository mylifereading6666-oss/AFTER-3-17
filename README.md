# AFTER 3:17

> 午前3時17分。その施設では、何かが起きる。

**AFTER 3:17** は、ブラウザで遊べる一人称視点の3Dホラーゲームです。暗い施設を探索して3つの手がかりを集め、出口を目指します。

## 特徴

- Three.jsによる3D施設と一人称視点
- ジャンプスケア、点滅する照明、環境音・効果音
- 3つの手がかりを探す探索目標
- PC、スマートフォン、タブレット向けの操作UI
- ポーズ、全画面切り替え、サウンドON/OFF
- 静的サイトとしてGitHub Pagesで公開可能

## 操作方法

### PC
- **W / A / S / D**：移動
- **マウス**：視点操作（ゲーム開始後に画面をクリック）
- **E / Enter**：調べる
- **P / Esc**：ポーズ

### スマートフォン・タブレット
- 画面左下の矢印：移動
- ゲーム画面をスワイプ：視点操作
- **調べる**：手がかりや出口を調べる
- **ポーズ**：ゲームを一時停止
- **全画面**：全画面表示の切り替え（ブラウザが対応している場合）

## ローカルで実行

`index.html` をブラウザで開きます。Three.jsはCDNから読み込むため、インターネット接続が必要です。

## GitHub Pagesで公開

1. リポジトリの **Settings → Pages** を開きます。
2. **Build and deployment → Source** で **GitHub Actions** を選択します。
3. Actionsタブで公開処理の結果を確認します。
4. 公開URLは **Settings → Pages** に表示されます。

## 注意

- 暗い画面や突然の音・映像演出があります。
- 初回の音声再生には、ゲーム画面でのユーザー操作が必要なブラウザがあります。
- 本作は静的ウェブゲームであり、サーバー側のゲーム状態保存機能はありません。
